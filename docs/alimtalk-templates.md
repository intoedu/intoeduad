# 알림톡 템플릿 문안 (심사 제출용)

> 이 문서의 본문은 `src/domain/messages.ts`와 같아야 합니다(단위 테스트로 확인). 문안을 바꿀 때는 두 곳을 함께 고치고, 카카오 심사를 다시 받습니다.
> 대체발송 문자·검수자 참고 의견은 이 문서에만 있습니다(솔라피 템플릿 등록 화면에 입력).

## 작성 기준

| 기준 | 근거 |
|---|---|
| 변수는 `#{변수명}`, 일반 버튼 최대 5개 | [솔라피 알림톡 가이드](https://solapi.com/guides/kakao-ata-guide) (2026-10-31 확인) |
| **버튼 링크에 변수를 쓸 때는 프로토콜을 고정**: `https://#{확인링크}` 형태(변수 값에는 https:// 를 넣지 않음) | 솔라피 템플릿 등록 화면 안내("링크를 변수 설정하는 과정에서 프로토콜(http) 고정으로 입력해야함", 2026-11-09), 가이드 예시 `https://#{google.com}` |
| 본문 최대 1,000자(변수 내용 포함) | 솔라피 템플릿 등록 화면 표시 "최대 1,000자" (2026-11-09). 내부 기준은 500자 이내 |
| 모든 변수에 예시 필요 / 변수만으로 된 본문·버튼명 변수·변수 40개 초과는 반려 | [카카오비즈니스 알림톡 심사 가이드](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit) |
| 광고성 내용이 한 줄이라도 있으면 발송 불가. 수신자가 요청·신청한 정보, 계약 이행 정보(서비스 확인·변경사항)는 정보성. "전송자의 필요에 따라 간헐적으로 발송되는 공지사항"은 불가 | 같은 심사 가이드 (2026-11-09 확인) |
| 검수자 참고 의견: 선택 사항, 수신자에게 보이지 않음 | 솔라피 알림톡 가이드 |
| 등록 완료된 템플릿은 수정 불가(새로 등록) | [솔라피 카카오 FAQ](https://solapi.com/guides/kakao-faq) |

**확인하지 못한 것**: 대체발송 문자에 `#{변수}`가 치환되는지(솔라피 문서에 명시 없음), 템플릿 카테고리 이름, 심사 기간 → 아래 "승인 후 시험 발송"으로 확인합니다.

**운영 원칙**: 고객이 신청·등록한 건에 대해서만 보냅니다. 리마인드·홍보성 반복 발송은 만들지 않습니다(SPEC 4-10). 학부모 메시지에는 커미션 정보를 넣지 않습니다. **광고 알림톡은 쓰지 않습니다**(광고는 마케팅 수신 동의가 필요하고 알림톡으로 보낼 수 없음).

### 승인 후 할 일
1. 받은 템플릿 ID를 웹앱 **설정 → 알림 → 승인된 템플릿 ID** 해당 칸에 입력(8칸 모두 있음)
2. **시험 발송**: 직원 본인 번호로 상담 신청 1건을 넣어 알림톡이 오는지, 버튼이 열리는지 확인
3. **대체발송 확인**: 카카오톡이 없는(또는 알림톡 수신 차단한) 번호로 1건 보내 문자에 `#{학부모명}` 같은 글자가 그대로 보이지 않는지 확인 → 그대로 보이면 대체발송 문자를 변수 없는 문구로 새로 등록
4. 반려되면 사유를 받아 문안을 고쳐 새로 등록(등록된 템플릿은 수정 불가) — 코드 문안도 함께 수정

## 1. 상담 신청 접수 안내 (`lead_received`)

- 보내는 때: 학부모가 상담 신청서를 제출한 직후 1회
- 누가 보내나: 자동
- 메시지 유형: 기본형 / 강조 표기 없음

### 본문

```
[인투유학] 상담 신청 접수 안내

#{학부모명}님, 인투유학 상담 신청이 접수되었습니다.

■ 자녀 이름: #{자녀명}
■ 상담 희망 일시: #{상담일시}

담당자가 신청 내용을 확인한 뒤 연락드립니다.
상담 방식(전화 또는 화상)은 문의 내용에 맞춰 담당자가 안내드립니다.

※ 이 메시지는 상담 신청에 따라 1회 발송되는 안내입니다.
```
