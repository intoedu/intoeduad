- 5·6번은 등록하신 프로그램의 계약 이행 정보(서비스 일정 확인·변경 사항)로 작성했습니다. 근거: 심사 가이드의 정보성 메시지 기준 "전송자와 수신자 간 계약 이행에 관한 정보 — 재화 및 서비스에 대한 설명서, 확인 및 보증사항, 변경사항". 다만 가이드에 "일정 안내"를 직접 든 예시는 없어서 승인 여부는 심사 결과로 확인해야 합니다.
- 변경 안내를 따로 만든 이유: 가이드가 알림톡을 "일정한 조건에서 항상 동일한 내용으로 발송되는 메시지"로 정의하고 "전송자의 필요에 따라 간헐적으로 발송되는 공지사항"은 금지하므로, 확정과 변경을 각각 정해진 조건의 메시지로 나눴습니다.
- OT 일시는 학부모 기준 **한국 시간**으로 적습니다(미국 현지 시간을 함께 적지 않음 — 혼동 방지).
- 5·6번의 웹앱 발송 기능(OT 일정 입력 → 발송·기록)은 아직 만들지 않았습니다. 승인 전·기능 완성 전에는 담당자가 카카오톡 채널로 같은 내용을 직접 보냅니다.

### 심사 제출 순서
1. 솔라피 콘솔에서 카카오톡 채널(인투유학) 연동 → 발신 프로필 키(pfId) 확인
2. 아래 6종을 본문·버튼·변수 예시 그대로 템플릿으로 등록(메시지 유형: 기본형, 강조 표기 없음) → 카카오 심사 요청
3. 승인되면 받은 템플릿 ID를 웹앱 설정 → 알림의 해당 칸에 입력(1~4번은 칸이 이미 있음, 5·6번은 기능을 만들 때 칸 추가)
4. 반려되면 사유를 받아 문안을 고쳐 새로 등록(등록된 템플릿은 수정 불가)

확인하지 못한 것: 템플릿 카테고리 선택 항목의 정확한 이름, 심사 소요 기간 — 솔라피 등록 화면에서 확인합니다.
