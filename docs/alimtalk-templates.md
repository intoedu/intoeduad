> 이 문서의 본문은 `src/domain/messages.ts`와 같아야 합니다(단위 테스트로 확인). 문안을 바꿀 때는 두 곳을 함께 고치고, 카카오 심사를 다시 받습니다.

## 작성 기준 (2026-10-31 확인)

| 기준 | 근거 |
|---|---|
| 변수는 `#{변수명}`, 웹링크 버튼 URL에 변수 사용 가능, 일반 버튼 최대 5개 | [솔라피 알림톡 가이드](https://solapi.com/guides/kakao-ata-guide) |
| 모든 변수에 예시 텍스트 필요 / 변수만으로 된 본문·버튼명 변수·변수 40개 초과는 반려 | [카카오비즈니스 알림톡 심사 가이드](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit) |
| 메시지 일부라도 광고성 내용이 있으면 발송 불가, 수신자 요청·신청에 따른 정보만 발송 가능, 요청 없는 반복 발송은 광고로 간주 | 같은 심사 가이드 |
| 등록 완료된 템플릿은 수정 불가(새로 등록) | [솔라피 카카오 FAQ](https://solapi.com/guides/kakao-faq) |

**확인하지 못한 것(TODO)**: 본문 최대 글자 수, 변수 값 안의 줄바꿈 허용 여부 → 본문은 500자 이내로 쓰고, 변수 값은 한 줄로만 채웁니다.

**운영 원칙**: 고객이 신청한 건에 대해 1회만 보냅니다. 리마인드·홍보성 반복 발송은 만들지 않습니다(SPEC 4-10). 학부모 메시지에는 커미션 정보를 넣지 않습니다.

**템플릿 코드 연결**: 승인 후 받은 템플릿 ID를 설정의 `solapi.templates` 해당 칸에 넣습니다(M13).

## 상담 신청 접수 안내 (`lead_received`)

- 보내는 때: 학부모가 상담 신청서를 제출한 직후 1회
- 메시지 유형: 기본형 / 강조 표기 없음

### 본문

```
[인투유학] 상담 신청 접수 안내

#{학부모명}님, 인투유학 상담 신청이 접수되었습니다.

■ 자녀 이름: #{자녀명}
■ 상담 희망 일시: #{상담일시}

담당자가 신청 내용을 확인한 뒤 연락드립니다.
상담 방식(전화 또는 화상)은 문의 내용에 맞춰 담당자가 안내드립니다.

※ 이 메시지는 상담 신청에 따라 1회 발송되는 안내입니다.
```

### 버튼

| 종류 | 버튼 이름 | 링크(모바일·PC) |
|---|---|---|
| 웹링크(WL) | 카카오톡으로 문의하기 | `#{카카오채널}` |

### 변수 예시

| 변수 | 예시 |
|---|---|
| `#{학부모명}` | 김민지 |
| `#{자녀명}` | 이하늘 |
| `#{상담일시}` | 2026년 11월 3일(화) 14:00 |
| `#{카카오채널}` | https://pf.kakao.com/_AkclX/chat |

## 캠프 등록 신청 접수·납부 안내 (`registration_payment_notice`)

- 보내는 때: 학부모가 캠프 등록 신청서를 제출한 직후 1회(대기 접수 제외), 대기에서 등록으로 바뀐 직후 1회
- 메시지 유형: 기본형 / 강조 표기 없음

### 본문

```
[인투유학] 등록 신청 접수 및 납부 안내

#{학부모명}님, #{학생명} 학생의 #{프로그램명} 등록 신청이 접수되었습니다.

■ 일정: #{일정}
■ 예약금: #{예약금}
■ 잔금: #{잔금}
■ 추가 납부: #{추가납부}
■ 입금 계좌: #{입금계좌}

입금하실 때 학생 이름으로 보내 주시면 확인이 빠릅니다.

■ 개인정보 파기 안내
제출하신 개인정보(여권·건강 정보 포함)는 프로그램 종료 후 #{파기일}에 파기됩니다.

※ 이 메시지는 등록 신청에 따라 1회 발송되는 안내입니다.
```

※ 이 메시지는 등록 신청하신 프로그램의 납부 조건 변경에 따라 발송되는 안내입니다.
